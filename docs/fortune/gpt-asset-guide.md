# GPT 앱으로 사주·타로 에셋 뽑기 가이드

> ChatGPT 앱에 아래 프롬프트를 **순서대로 복사·붙여넣기**하면 된다. 받은 파일은 §7 규칙대로 이름을 바꿔 올려주면 Claude가 페이지에 붙이고 모션을 입힌다.
> 참고 시안: `docs/fortune/mockups/saju-page.png`, `tarot-page.png` (GPT 대화에 이미지로 첨부하면 결과가 훨씬 일관된다)

---

## 0. 작업 순서 한눈에

| 순서 | 할 일 | 대화창 | 결과물 |
|---|---|---|---|
| 1 | 스타일 기준 고정 (§1) | **에셋용 대화 1개**를 새로 열어 계속 사용 | 스타일 시트 이미지 1장 |
| 2 | 페이지 시안 2종 (§2) | 별도 대화 | 시안 이미지 2장 |
| 3 | 사주 에셋 (§3) | 1번 대화 | 마스코트, 일간 캐릭터 10, 아이콘 |
| 4 | 타로 에셋 (§4) | 1번 대화 | 카드 뒷면·프레임, 메이저 22장, 마이너 56장 |
| 5 | 공통 UI 에셋 (§5) | 1번 대화 | 별·달 배경, 배지 |
| 6 | 모션용 프레임 (§6) | 1번 대화 | 스프라이트 시트 |

**팁**
- 같은 대화창에서 이어 만들어야 그림체가 유지된다. 한 대화가 길어져 그림체가 흐트러지면 새 대화에 §1 프롬프트와 스타일 시트 이미지를 다시 넣고 이어간다.
- 한 번에 1~4장씩 요청한다. 한꺼번에 많이 요청하면 품질이 떨어진다.
- 마음에 드는 결과가 나오면 "이 그림체를 기준으로 계속"이라고 못 박아 둔다.

## 1. 스타일 기준 프롬프트 (가장 먼저, 1회)

```text
지금부터 한 웹사이트의 일러스트·아이콘 에셋을 여러 장 만들 거야. 모든 에셋은 아래 스타일 규칙을 반드시 지켜줘.

[스타일 규칙]
- 레트로 픽셀 아트. 32×32 또는 64×64 픽셀 격자로 그린 뒤, 계단 현상이 유지되도록 최근접(nearest-neighbor) 방식으로 확대한 것처럼 보이게. 안티에일리어싱·그라데이션·흐림 금지.
- 외곽선: 1픽셀 두께, 진한 남보라 #1b1530
- 팔레트(이 색 위주로만 사용):
  남보라 #1b1530, 짙은 남보라 #120e22, 보라 #4e43a0, 연보라 #6b5fa0, 라일락 #c8c1e2, 종이색 #f3f1f8,
  민트 #5be08a, 짙은 민트 #2f9a5a, 달빛 노랑 #ffe7a3, 금색 #c9a85a, 주황 #ff8a3d, 산호 #ff8a8d, 빨강 #b8402c,
  오행 색: 목 #1e7a45, 화 #b8402c, 토 #8a6216, 금 #8a83a8, 수 #2c3e8a
- 분위기: 귀엽고 따뜻함, 교사·학교 친화적. 무섭거나 선정적인 요소 금지.
- 배경: 특별히 말하지 않으면 투명 배경(PNG), 정사각형 1024×1024, 대상은 가운데에 두고 여백 10%.
- 글자는 그림 안에 넣지 마(제가 따로 지정할 때만).
- 기존 타로 덱(라이더-웨이트 등)이나 유명 캐릭터의 구도·디자인을 베끼지 말고 오리지널로.

먼저 이 규칙을 보여주는 "스타일 시트" 한 장을 만들어줘: 팔레트 색 칩, 픽셀 별·달·구름·꽃 샘플, 갓 쓴 작은 선비 캐릭터 1개.
```

→ 결과 저장 파일명: `style-sheet.png`

## 2. 페이지 시안 프롬프트 (별도 대화)

참고 이미지 첨부: `saju-page.png` 또는 `tarot-page.png`

### 2-1. 사주방
```text
첨부한 와이어프레임을 참고해, 교사용 "심심풀이 사주" 웹페이지의 데스크톱(가로 1440px) 완성 시안 이미지를 만들어줘. 세로로 긴 한 장.

[톤] 레트로 픽셀 감성 + 깔끔한 웹 UI. 한글 픽셀 폰트 느낌의 제목. 남보라 밤하늘 #1b1530, 민트 #5be08a 주 버튼(아래에 짙은 초록 그림자), 라일락 #c8c1e2, 바탕은 연보라 종이 #f3f1f8에 옅은 격자.
[구성]
1. 헤더: 로고 "SEONBI'S LAB", 메뉴(소개/배움터/놀이터), "오늘의 운세" 버튼
2. 밤하늘 히어로: 픽셀 별·초승달, 갓 쓴 선비 마스코트와 말풍선. 제목 "선비의 사주방". 오른쪽에 입력 카드(양력/음력, 생년월일, 태어난 시각, 성별 선택, 민트 버튼 "사주 펼쳐보기")
3. 사주 원국 8칸 타일(乙未 丙子 丁巳 戊辰, 오행 색) + 일간 캐릭터 카드 "태양 선생님"
4. 오행 오각형 레이더 + 오늘의 운세(원형 게이지 78점, "성과의 날")
5. 대운 인생 그래프(꺾은선, "지금 여기" 강조)
6. 질문 메뉴 타일 12개 + "선비에게 직접 묻기" 입력 바
7. 추천 콘텐츠 카드 3개, 하단 고지문
글자는 모두 한국어로.
```

### 2-2. 타로방
```text
첨부한 와이어프레임을 참고해, 같은 사이트의 "타로방" 데스크톱(1440px) 완성 시안 이미지를 세로로 긴 한 장으로 만들어줘.
배경 전체는 짙은 밤하늘 #120e22, 중앙에 은은한 보라빛 광원. 픽셀 별.
[구성]
1. 제목 "선비의 타로방", 주제 탭(오늘/연애/금전/일·진로/학업/관계/선택)
2. 배열법 카드 4개(원카드, 쓰리카드[선택됨], A냐 B냐, 켈틱 크로스), 질문 입력창
3. "끌리는 카드를 3장 골라주세요" + 카드 13장 부채꼴, 고른 2장은 위로 떠오르고 민트 테두리
4. 과거·현재·미래 결과 카드 3장(크림색 카드, 금 테두리, 픽셀 일러스트: 별 / 태양(뒤집힘) / 컵 3)
5. 총평 패널 + 민트 버튼 "선비에게 더 깊이 묻기"
6. 다른 배열법 버튼 6개, 밝은 영역에 추천 콘텐츠 3개
글자는 한국어로.
```

## 3. 사주 에셋

### 3-1. 선비 마스코트 (A1)
```text
스타일 규칙대로 마스코트 캐릭터를 만들어줘.
- 캐릭터: 검은 갓을 쓰고 흰 도포를 입은 젊은 선비. 2~3등신, 동글한 얼굴, 볼터치. 손에 작은 부채.
```

```text
마이너 카드용 슈트 상징 4개를 32×32 픽셀 아이콘으로 가로 한 줄로 만들어줘:
```

```text
[슈트] [숫자/인물] — 상징 소품을 [개수]개 배치하고, 장면: [장면 설명]
```

| 숫자 | 장면 가이드 (슈트 소품을 그 개수만큼 배치) |
|---|---|
| Ace | 구름에서 나온 손이 소품 하나를 내민다 — 새 기회 |
| 2 | 두 갈래 길 앞에서 고민 / 두 사람이 마주 봄 — 선택·균형 |
| 3 | 세 사람이 함께 축하하거나 협력 — 성장·협력 |
| 4 | 소품을 단단히 지키거나 쉬는 모습 — 안정·휴식 |
| 5 | 의견 다툼, 쓰러진 소품 — 갈등 (과격하지 않게) |
| 6 | 나누거나 함께 행진 — 회복·나눔 |
| 7 | 언덕 위에서 버티거나 고민하며 고르는 모습 — 도전·평가 |
| 8 | 소품이 빠르게 날아가거나 열심히 작업 — 속도·몰입 |
| 9 | 거의 다 이룬 모습, 소품에 둘러싸임 — 성취 직전 |
| 10 | 소품을 한가득 짊어짐 / 가족이 모인 마을 — 완성·과부하 |
| Page(시종) | 소품을 신기하게 바라보는 어린 학생 |
| Knight(기사) | 말을 타고 소품을 들고 달리는 젊은이 |
