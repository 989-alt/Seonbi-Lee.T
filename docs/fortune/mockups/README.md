# 사주·타로 페이지 시안 v1

| 파일 | 내용 |
|---|---|
| `saju-page.svg` / `.png` | 사주방 데스크톱 1440px 시안 |
| `tarot-page.svg` / `.png` | 타로방 데스크톱 1440px 시안 |

- 톤: 사이트 팔레트(남보라 `#1b1530`, 민트 `#5be08a`, 라일락 `#c8c1e2`)와 갈무리 픽셀 폰트를 따른다. 사주방은 밝은 종이 바탕과 밤하늘 히어로, 타로방은 전체 밤하늘 배경이다.
- 예시 데이터는 실제로 계산한 값이다. 1988-05-21 15:20, 여성 → 乙未 丙子 丁巳 戊辰. 오늘(2026-11-23)의 일진은 辛丑이다.
- 시안 위의 원형 마커 중 **A = 에셋**, **M = 모션**이다. 구현할 때는 마커를 지운다.

## 사주방

| 마커 | 종류 | 내용 |
|---|---|---|
| A1 | 에셋 | 선비 마스코트(갓 쓴 픽셀 캐릭터). 대기·말하기·놀람 3가지 표정, 64px 그리드 스프라이트 |
| A2 | 에셋 | 일간 캐릭터 10종(甲 큰 나무, 乙 덩굴꽃, 丙 태양, 丁 촛불, 戊 큰 산, 己 논밭, 庚 바위·칼, 辛 보석, 壬 바다, 癸 이슬비). 픽셀 일러스트 |
| A3 | 에셋 | 질문 메뉴 아이콘 12종. 이모지 대신 픽셀 아이콘 세트로 교체 |
| M1 | 모션 | 히어로 별 깜빡임(무작위 지연), 달이 천천히 위아래로 흔들림, 마스코트 말풍선 타이핑 효과 |
| M2 | 모션 | CTA를 누르면 버튼이 눌리는 애니메이션(그림자 5px→0), 이어서 결과로 스크롤 |
| M3 | 모션 | 만세력 8글자가 한 글자씩 뒤집히며 등장(연→월→일→시). 일간 카드가 마지막에 빛남 |
| M4 | 모션 | 오행 레이더 다각형이 중심에서 펼쳐짐, 값 숫자 카운트업 |
| M5 | 모션 | 운세 게이지가 0→78로 차오름, 테마 배지가 튀어오름 |
| M6 | 모션 | 인생 그래프 선이 왼쪽부터 그려짐, '지금 여기' 하이라이트가 깜빡임, 점에 마우스를 올리면 툴팁 |

## 타로방

| 마커 | 종류 | 내용 |
|---|---|---|
| A1 | 에셋 | 배열법 썸네일 아이콘(원카드·쓰리·선택·켈틱 + 확장 배열법) |
| A2 | 에셋 | 카드 뒷면 1종(픽셀 패턴 + 민트 십자 문양) |
| A3 | 에셋 | 카드 앞면 78장. 자체 제작 픽셀 일러스트이며, 1차로 메이저 22장을 먼저 만든다. 프레임·숫자·이름 레이아웃은 공통 |
| M1 | 모션 | 다시 섞기: 카드가 가운데로 모였다가 리플 셔플 후 다시 부채꼴로 펼쳐짐 |
| M2 | 모션 | 부채꼴 덱. 마우스를 올리면 카드가 살짝 떠오르고, 클릭하거나 위로 끌면 뽑힘. 낮은 확률로 '점프 카드' 이벤트 |
| M3 | 모션 | 결과 카드가 3D로 뒤집힘(rotateY). 역방향은 뒤집힌 뒤 180° 회전. 해석 텍스트는 아래에서 페이드인 |
| M4 | 모션 | 총평 카드가 등장할 때 테두리를 따라 민트 빛이 한 바퀴 돎. 'AI로 더 묻기'를 누르면 답이 스트리밍되며 타이핑 |

## 확정 후 다음 단계
1. 모바일(390px) 시안을 만든다.
2. 에셋을 제작한다. 픽셀 아트는 SVG(`shape-rendering: crispEdges`)로 만들고, 스프라이트는 PNG 2x로 만든다.
3. 모션을 구현한다. 기본은 CSS keyframes와 Web Animations API로 하고, 카드 드래그만 포인터 이벤트로 처리한다. `prefers-reduced-motion`을 지원한다.
