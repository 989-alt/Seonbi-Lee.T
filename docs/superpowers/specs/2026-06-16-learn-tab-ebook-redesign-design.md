# 배우기(/learn) 탭 개편 설계 — 전자책 리더 + 스킬 갤러리 필터

- 날짜: 2026-06-16
- 범위: `/learn` 페이지 한정 (코스 상세 `/learn/[slug]`는 변경하지 않음)
- 대상 사용자: 비개발자 교사 (Claude A→Z 학습 허브 이용자)

## 1. 배경 / 문제

현재 `/learn` 페이지의 "단계별 학습"과 "스킬 갤러리"가 사용하기 불편하다.

1. **색이 너무 강렬해 눈이 아프다.** 원인은 Neon Laboratory 팔레트의 네온색을 *단색으로 채우고*(예: 활성 태그 `bg-primary`), *제목 전체를 네온색*으로 칠한 것.
2. **한 항목씩 토글하는 아코디언**이 번거롭다. 전자책처럼 챕터 책갈피로 이동하고 페이지를 넘기며 읽고 싶다.
3. **스킬 갤러리에 필터가 없다.** 태그가 표시만 되고 선택해서 거를 수 없다. 또 카드가 한 번에 너무 많이 나온다.

## 2. 목표 (성공 기준)

- 학습 경로가 "목차 사이드바 + 본문(페이지)" 전자책 리더로 동작한다.
- 강조색이 차분한 틸(`#4F9AA1`, 글로우 없음)로 바뀌고, 네온 단색 채움·제목 전체 네온이 사라진다.
- 스킬 갤러리에서 태그를 다중 선택(AND)으로 거를 수 있고, 상위 8개만 먼저 보이며 "펼치기"로 나머지를 본다.
- 기존 Neon Lab 컨셉(각진 모서리, `// SECTION` 모노스페이스 라벨, Space Grotesk 헤드라인)을 유지한다.
- 코스 상세 페이지와 공용 컴포넌트(`ResourceAccordion`)의 동작은 그대로 보존한다.

## 3. 비목표 (이번에 하지 않음)

- 코스 상세(`/learn/[slug]`)의 레슨/갤러리 UI 변경
- 사이트 전역 팔레트(globals.css `@theme`) 교체 — 강조색 변경은 `/learn`의 새 컴포넌트 범위에서만 적용
- 레슨 본문을 더 잘게 쪼개 "텍스트 페이지네이션" 하는 것 (한 레슨 = 한 페이지, 길면 페이지 내부 스크롤)
- 데이터 모델/스키마(Supabase `resources`) 변경

## 4. 강조색 토큰

- 차분한 틸 `#4F9AA1` (글로우 없음)을 학습 경로·갤러리 필터의 **상호작용 강조색**으로 사용.
- 적용 위치는 "얇은 강조"로 한정: 활성 책갈피 리본(2px), 현재 레슨 점, 작은 모노스페이스 라벨, 진행바, 활성 태그 칩 테두리.
- 금지: 네온 단색 배경 채움, 제목 전체 네온 칠, 텍스트/박스 글로우(shadow).
- 제목은 거의 흰색(`on-surface`), 본문은 차분한 회색(`on-surface-variant`).
- 구현 방식: 새 컴포넌트에서 쓰는 로컬 CSS 변수(예: `--learn-accent: #4f9aa1`)로 정의. 전역 팔레트는 건드리지 않는다.

## 5. 학습 경로 — `LessonReader` (신규 클라이언트 컴포넌트)

`/learn/page.tsx`의 LEARNING PATH 섹션에서 `<LearnBrowser>` 대신 `<LessonReader lessons={lessons} />`를 사용. (`LearnBrowser`는 더 이상 `/learn`에서 쓰이지 않게 됨 → 다른 사용처가 없으면 제거 대상으로 기록만, 삭제는 구현 시 확인 후.)

### 책 매핑
- 챕터(책갈피) = 레벨. `LEVEL_ORDER`에서 **데이터가 있는 레벨만** 노출 (입문·기초·실무·심화·바이브코딩). `LEVEL_TAG`(`01 / ENTRY` 등)·`LEVEL_LABEL`(한글) 재사용.
- 페이지 = 그 레벨의 레슨 1개. 레슨 순서는 쿼리 정렬(`sort_order` → `created_at`) 그대로.

### 레이아웃
- 데스크탑: 좌측 목차 사이드바(고정 폭 ~248px) + 우측 본문. 둘 다 각진 테두리.
- 모바일(<md): 사이드바가 본문 위 접이식 "목차" 패널로 전환 (기본 접힘, 현재 챕터/레슨만 표시 → 탭하면 전체 목차).

### 사이드바 (목차 / 책갈피)
- `// 목차 · INDEX` 모노스페이스 라벨.
- 챕터 행: `01` 번호 태그 + 레벨명(대문자) + 펼침 화살표.
- **토글 동작:** 챕터는 기본 접힘(▸). 클릭하면 그 레벨의 레슨 목록이 펼쳐짐(▾). 단, **현재 레슨이 속한 챕터는 기본 펼침**.
- 활성 챕터: 왼쪽에 2px 틸 리본 + 아주 옅은 좌→우 그라데이션.
- 레슨 행: 작은 사각 점 + 레슨 제목. 현재 레슨은 흰색 텍스트 + 틸 점. (읽음 표시는 선택: 방문한 레슨 점을 회색 채움 — 상태 비저장, 세션 내 표시만으로 충분하면 생략 가능. MVP에선 생략.)

### 본문 (페이지)
- 상단 eyebrow: `입문 · 책갈피 02 / 05` (현재 챕터명 + 챕터 내 위치).
- 레슨 제목(거의 흰색).
- 본문: `body_md`(Markdown), 링크, 프롬프트. **기존 `ResourceAccordion`이 펼쳤을 때 쓰는 렌더링(Markdown / // LINKS / // PROMPTS + 복사 가능한 PromptBlock)을 재사용**한다 — 중복 구현하지 말고 공용 조각으로 추출(예: `LessonBody`, `PromptBlock`)해서 `LessonReader`가 사용. `ResourceAccordion`의 화면/동작은 바뀌지 않아야 함(코스 페이지 보존).
- 하단 푸터: `◀ 이전(이전 레슨 제목) · 02 / 05 · 다음(다음 레슨 제목) ▶` + 얇은 진행바.

### 페이지 넘김 동작
- ◀▶는 **노출된 모든 레벨의 레슨을 LEVEL_ORDER 순으로 평탄화한 전체 시퀀스**를 따라 이동 (책을 처음부터 끝까지 읽는 흐름). 한 챕터 끝에서 "다음"을 누르면 다음 챕터 첫 레슨으로 넘어가고, 사이드바에서 해당 챕터가 자동 펼쳐짐.
- `02 / 05` 카운터·진행바는 **현재 챕터 내 위치** 기준.
- 첫 레슨에서 ◀ 비활성, 마지막 레슨에서 ▶ 비활성.
- 넘길 때 본문에 좌우 슬라이드 + 페이드 전환. `prefers-reduced-motion`이면 전환 생략.

### 상태 (컴포넌트 내부, 비저장)
- `currentLessonId`: 현재 페이지. 초기값 = 첫 노출 레벨의 첫 레슨.
- `expandedChapters: Set<level>`: 사이드바에서 펼친 챕터. 초기값 = 현재 레슨의 챕터.
- 챕터 클릭 = 해당 챕터 펼침 토글 (현재 페이지는 바뀌지 않음). 레슨 클릭 = 그 레슨을 현재 페이지로.

### 비고
- 기존 LearnBrowser의 "토픽 태그 필터"는 리더에서 **제거**. 레슨은 챕터→레슨으로만 탐색 (단순화).
- 데이터 0개: "아직 공개된 학습 자료가 없습니다." (기존 문구 유지).

## 6. 스킬 갤러리 — `SkillsGallery` (신규 클라이언트 컴포넌트)

`/learn/page.tsx`의 SKILLS GALLERY 섹션의 인라인 그리드를 `<SkillsGallery gallery={gallery} />`로 대체. **카드 자체는 기존과 동일** (제목·설명·태그 칩, 카드 전체가 외부 링크).

### 태그 필터 (다중 선택, AND)
- 갤러리 항목들의 태그를 모아 칩 바로 표시 (`전체` + 각 태그). 정렬: 사용 빈도 높은 순.
- 다중 선택: 여러 태그를 동시에 켤 수 있음. 활성 칩은 틸 테두리 + 옅은 틸 배경 + `✕`로 해제. `전체`로 초기화.
- **AND 로직:** 선택한 태그를 **전부 포함**한 스킬만 표시. 선택 없음 = 전체 표시.
- 활성 필터에 해당하는 카드 내 태그 칩은 틸로 강조.

### 상위 8개 + 펼치기
- (필터 적용 후) 결과의 **상위 8개만** 먼저 표시.
- 결과가 8개 초과 & 접힘 상태: `펼치기 ▾ · N개 더 보기` 버튼 → 누르면 나머지가 같은 그리드로 이어 붙음(접힘 상태 `expanded=true`).
- 펼친 상태: `접기 ▲` 로 복귀.
- 결과 ≤ 8개: 토글 없이 전부 표시.
- 필터(`selectedTags`)가 바뀌면 `expanded`는 false로 리셋.

### 상태 (컴포넌트 내부, 비저장)
- `selectedTags: Set<string>`
- `expanded: boolean`

### 엣지 케이스
- 태그가 하나도 없음 → 필터 바 미표시.
- 필터 결과 0개 → "이 조건에 해당하는 스킬이 없습니다."
- 갤러리 0개 (관리자) → 기존 "아직 등록된 스킬이 없습니다." 유지.

## 7. 컴포넌트 구조 요약

```
/learn/page.tsx
  ├─ LEARNING PATH 섹션 → <LessonReader lessons={lessons} />   (신규)
  └─ SKILLS GALLERY 섹션 → <SkillsGallery gallery={gallery} /> (신규)

신규/공용:
  - src/components/learn/LessonReader.tsx     (사이드바 + 본문 + 넘김)
  - src/components/learn/SkillsGallery.tsx    (태그 필터 + 8개 + 펼치기)
  - src/components/resources/LessonBody.tsx   (body_md + 링크 + 프롬프트 렌더 — 공용 추출)
  - src/components/resources/PromptBlock.tsx  (복사 가능한 프롬프트 블록 — ResourceAccordion에서 추출)

보존(변경 없음): ResourceAccordion(코스 페이지에서 계속 사용), /learn/[slug]
```

공용 추출(`LessonBody`/`PromptBlock`)은 중복 구현을 막기 위함이며, `ResourceAccordion`의 외형·동작은 동일하게 유지하는 선에서만 진행한다. (추출이 `ResourceAccordion`에 영향을 준다면, 영향 범위를 구현 계획에서 명시하고 동작 보존을 검증한다.)

## 8. 빌드 / 기술 제약

- 이 저장소는 커스텀 Next.js다(루트 `AGENTS.md`). **코드 작성 전 `node_modules/next/dist/docs/`의 관련 가이드를 먼저 읽는다.**
- 모든 신규 컴포넌트는 `"use client"` (상태/상호작용 필요).
- 접근성: 사이드바 챕터 토글·레슨 선택·페이지 넘김 버튼은 키보드 포커스 가능, `aria-expanded`/`aria-current` 부여. `prefers-reduced-motion` 존중.
- 배포: 기존 수동 Vercel promote 플로우 유지.

## 9. 검증 (구현 후)

- `/learn`에서 챕터 토글·레슨 선택·◀▶ 넘김·챕터 경계 넘김이 동작한다.
- 강조색이 틸이고 네온 단색 채움/제목 네온/글로우가 없다.
- 갤러리: 태그 다중 선택(AND)으로 결과가 줄고, 8개 초과 시 펼치기/접기가 동작하며, 필터 변경 시 다시 8개로 접힌다.
- 코스 상세(`/learn/[slug]`)와 코스 카드/아코디언은 이전과 동일하게 보인다(회귀 없음).
- 모바일에서 목차가 접이식으로 동작한다.
